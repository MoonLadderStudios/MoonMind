# Codex-through-Omnigent cutover contract v1

MoonLadderStudios/MoonMind#3518 introduces the versioned, fail-closed Codex
cutover authority and support matrix. The initial phase is `internal`; this
release does not claim unsupported live combinations and does not remove the
direct runtime. Operators promote Create, schedules/presets, broad default,
direct-disable and retirement separately, using fresh generation-bound live
evidence and objective rollback thresholds.

The exact Omnigent server/host digests, protocol, architecture and protected
report define upstream compatibility. Direct historical events retain
`codex_direct_compat` provenance and their read/replay contracts survive launch
disablement. Claude-through-Omnigent parity is deferred.
