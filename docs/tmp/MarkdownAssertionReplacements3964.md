## Checks retained or strengthened

- **Internal links and anchors:** Required fast-unit CI invokes the existing local link checker over its canonical scope. External URLs are not fetched in CI. Missing targets and anchors have negative controls. Seven baseline findings were repaired: three nonbreaking-hyphen heading mismatches and four missing reference definitions. The standalone CLI remains advisory, as documented by its owner.
- **Metadata and claims:** The existing architecture checker now reads explicit header fields and reports invalid/empty classes; the legacy incremental policy for undeclared headers remains. Mutation controls cover class, authority, malformed IDs and duplicate IDs. Templates keep schema and stable-claim checks.
- **Shipped Skills:** Every shipped bundle is parsed through the production frontmatter/input-contract parser and resolved by `BuiltInSkillLoader`. Required dependencies must exist. Corrupted YAML, an unknown terminal contract and a path traversal in the terminal artifact are rejected. Existing instruction-semantic tests are retained because parsing frontmatter alone cannot establish their meaning.
- **Examples:** JSON examples continue to be parsed; the canonical agent request is validated by its real Pydantic model, including a negative identity case. Structured Docker examples keep typed policy values and independent public-admission checks.
- **Security:** No security instruction guard was removed from an executable Skill. Existing Docker authority, container lifecycle, Omnigent no-fallback and credential/recovery safeguards remain in their owning suites. The original recovered bag-of-words helper was removed entirely; word presence is not evidence of a denial.

## CI ownership

Documentation and the added contract/regression tests retain the existing `unit_fast` ownership from `tests/conftest.py`; no shard or marker alias was introduced. `tools/select_test_suites.py` now selects that shard for Markdown changes, while documentation-only changes continue to avoid heavy integration, exact-artifact and Omnigent gates. Changes to the selector itself retain its existing full-suite fail-open policy. Negative selector checks and actual fast-shard collection verify that surviving tests are not orphaned.

This report does not claim all text assertions are incidental. Authority denials, security rules, executable Skill instructions, stable machine identifiers, and deliberate documentation-policy requirements are retained when a word-level edit would change the contract rather than merely its presentation.
